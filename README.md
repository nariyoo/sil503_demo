# sil503_demo

Demo applications for the SIL 503 activity.

## Washtenaw Welcome Desk

`index.html` is a single-file, client-side demo app for refugee resettlement caseworkers in Ann Arbor and Washtenaw County. Open it in any browser; there is no build step and no backend.

- **Today**: overdue and upcoming core services across the caseload, plus the next 7 days of appointments with interpreter needs.
- **Cases**: each family's progress through the 30-day reception and placement core services (housing, SSA, MDHHS benefits, ESL, health screening, school enrollment and more), with household details and case notes.
- **Resources**: a searchable directory of real Washtenaw County organizations by category (resettlement, legal, health, food, English, employment, transit, safety).
- **Phrases**: short scheduling and safety phrases in Arabic, Dari, Spanish and Ukrainian.

All families and appointments are fictional demo data, with dates computed relative to today. Changes are saved only in the browser's local storage; "Reset demo data" restores the sample set. Confirm resource details and have translations reviewed by native speakers before real use.
